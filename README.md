## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/mouleessv/Calculator.git
```

### 2. Open the project folder

```bash
cd Calculator
```

### 3. Compile the Java program

```bash
javac Calculator.java
```

### 4. Run the program

```bash
java Calculator
```

*These commands assume the source file declares a class named `Calculator` and does not use a Java package.*
